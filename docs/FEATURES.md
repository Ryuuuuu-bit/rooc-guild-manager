# คู่มือใช้งานทีละหน้า

> แอดมิน = มี role/user ID ตาม `DISCORD_ADMIN_ROLE_IDS` / `DISCORD_ADMIN_USER_IDS` · สมาชิก = มี role กิลด์ (`Rooc`)
> ส่วนที่เขียนว่า *(แอดมิน)* สมาชิกทั่วไปจะไม่เห็น

## ทุกหน้า (App shell)

- **เมนูซ้าย** (จอ ≥ 1024px) — ไอคอนเส้นบาง, เมนูที่เลือกเป็นสีทอง, หัวข้อกลุ่ม Events / Logs & Stats / System
  - **Badge งานค้าง** *(แอดมิน)*: Members = ยังไม่ตั้งอาชีพ หรือ PVP stats ไม่อัปเดตเกิน 14 วัน · Party = คนที่นั่งในปาร์ตี้แต่ลารอบนี้ · Activity = รายการใหม่วันนี้ · Leave Stats = คนเกินโควต้าเดือนนี้
  - **LIVE** บน Check-in เมื่อมีกิจกรรมกำลังแข่ง (ทุกคนเห็น)
  - **กล่องรอบถัดไป** ใต้เมนู: นับถอยหลัง/เหลือกี่นาที, จำนวนคนในห้องเสียง, จำนวนคนลา — กดแล้วไปหน้า Check-in
- **แท็บเล็ต** (768–1023px) เมนูย่อเหลือไอคอน · **มือถือ** (< 768px) แถบล่าง Home / Members / Party / Loot / More (More เปิดแผ่นหน้าที่เหลือ)
- **ค้นหา `Ctrl K`** (หรือปุ่ม Search): พิมพ์ชื่อหน้า, ชื่อสมาชิก (Enter = เปิดโปรไฟล์) หรือทางลัด เช่น Run a loot round
- **หน้าต่างยืนยัน / แจ้งเตือน** แบบเดียวกันทุกหน้า — ปุ่มลบ/เตะ/ล้างเป็นสีแดง, แจ้งผลเป็นแถบด้านล่าง (บางอันมีปุ่ม Undo)

## Overview `/`

- Hero รอบถัดไป: นับถอยหลัง, จำนวนลา, ความพร้อมของกระดาน (ที่นั่ง/ว่าง/คนลาที่ยังนั่งอยู่), อัตรามารอบก่อน
- *(แอดมิน)* **Needs attention**: PVP ไม่อัปเดต, ไม่มีอาชีพ, ขาด 3 รอบติด, เกินโควต้า, สมาชิกใหม่ — กดแล้วไปหน้า Members พร้อมตัวกรอง
- KPI + sparkline, กราฟการเข้าร่วม 12 รอบล่าสุด (มา/ลา/ขาด/รอบพัก, เส้นเป้า 85%, กรอง GL/WOE), เข้า-ออกรายสัปดาห์, สัดส่วนอาชีพ, shout-outs, ฟีดกิจกรรม

## Members `/members`

- มุมมองตาราง / roster, ค้นหา, กรองสถานะ (Active/Benched/Left/Kicked), อาชีพ, ยศ Discord
- *(แอดมิน)* ชิป "ต้องดูแล": ไม่มีอาชีพ, ไม่มีชื่อในเกม, PVP เก่า, เกินโควต้า, เข้าร่วมต่ำ, ขาด 3 รอบติด, ใหม่ 30 วัน
- *(แอดมิน)* แถบเข้า-ขาด 8 รอบล่าสุดต่อคน (มา / ลา / ขาด / ไม่ถูกคาดหวัง / รอบพัก)
- กดชื่อ → drawer โปรไฟล์ย่อ (กิจกรรมล่าสุด, bench) หรือเปิดหน้าโปรไฟล์เต็ม
- *(แอดมิน)* เลือกหลายคน → Bench/Unbench, Copy `<@mention>`, Export CSV
- **หน้าโปรไฟล์** `/members/[id]`: แก้ข้อมูล, อาชีพหลัก/รอง, โน้ตภายใน, ลงลาย้อนหลัง, bench, แบนจากคิวประมูล (กำหนดวัน), เตะออกจาก Discord, ประวัติกิจกรรมและ PVP

## Party `/party`

- กระดาน (GL / WOE — ผูกกับ check-in event จากชื่อกระดาน) → กลุ่ม (เช่น Main Stage) → ปาร์ตี้ละ 5 ที่นั่ง
- ย้ายคน: ลาก-วาง, แตะชื่อแล้วแตะที่นั่ง, หรือ "+ Select Member" ในที่นั่งว่าง
- ที่นั่งแต่ละช่องเลือก **อาชีพที่เล่นในช่องนี้** ได้ทุกอาชีพ (ติดป้าย (หลัก)/(รอง) ตามที่สมาชิกลงไว้) โดยไม่แก้โปรไฟล์
- **ลา**: ปุ่ม Leave ในที่นั่ง (ลารอบปัจจุบัน — ยังนั่งที่เดิมแต่จาง) หรือลากลงโซน "ลา" · Return = ยกเลิกลา
- **ป้ายความพร้อม**: นับถอยหลัง, นั่งแล้ว/ทั้งหมด, นั่งแต่ลา, ปาร์ตี้ที่ขาดอาชีพตาม recipe, ความต่าง CP ของกลุ่ม
- **Recipe** (ต่อกระดาน) เช่น Priest ×1, B/D ×1 → ปาร์ตี้ที่ขาดขึ้นป้าย "ขาด"
- หัวการ์ดปาร์ตี้: CP รวม (จาก PVP stats ล่าสุด), อีโมจิอาชีพ, แถบพลังเทียบค่าเฉลี่ยกลุ่ม
- **หาแทน**: ปุ่มบนที่นั่งของคนลา → รายชื่อแนะนำ (อาชีพเดียวกันที่ว่าง → คนที่มีเป็นอาชีพรอง → อาชีพเดียวกันจากกลุ่มอื่น) เรียงตาม CP คลิกเพื่อลงแทน (ถาวร — คนลายังอยู่ในโซนลา)
- **Auto-balance**: สลับเฉพาะคนอาชีพเดียวกันระหว่างปาร์ตี้ที่เต็ม เพื่อให้ CP ใกล้กัน (ไม่ขยับคนลา, คนไม่มี PVP นับเป็นค่ามัธยฐาน)
- **Undo** ย้อนการย้ายที่นั่ง/หาแทน/Auto-balance/เปลี่ยนอาชีพในช่อง (ไม่ย้อนการลา)
- ไฮไลต์อาชีพ, แผงข้าง (ต้องหาแทน, รอลงปาร์ตี้, Party power, Changes)
- **Screenshot mode** (ซ่อนปุ่มทั้งหมด 8 คอลัมน์) · **Announce as Image** โพสต์ภาพผังลง Discord
- *(แอดมิน)* โพสต์แผง "เลือกอาชีพ" และแผง "ห้องลา" ลง Discord

## Random Picker `/random`

- กองสุ่ม: ไม่รวมคนพัก, ไม่ซ้ำคนเดิม, **เฉพาะคนในห้องเสียง**, เลือกอาชีพได้หลายอัน
- กด Randomize! (มีเสียง เปิด/ปิดได้), ประวัติคนที่ได้ + Reset

## Loot Queue `/loot-queue`

- การ์ดหมวด: ใครได้ถัดไป + รันล่าสุดเมื่อไหร่ *(แอดมิน: เลื่อนซ้าย/ขวา, เปลี่ยนชื่อ, ลบ, เพิ่มหมวด)*
- KPI: รอบนี้ของคิว (lap), รันล่าสุด, เฉลี่ยต่อรอบ, สมาชิกที่ยังไม่อยู่ในคิว (+ ปุ่มเพิ่มท้ายคิวทั้งหมด)
- *(แอดมิน)* **Run round**: ใส่จำนวน (มีชิปจำนวนที่ใช้บ่อย), ชื่อรอบ (ชิป gl/woe วันนี้-ถัดไป), เลขเริ่ม/ต่อจากหมวดอื่น
  - เห็น **เส้นตัด** ในคิวและ **ตัวอย่างข้อความ Discord** ก่อนกด · คนแบน/พักถูกข้ามแต่คงตำแหน่ง
  - กด Run → คัดลอกข้อความอัตโนมัติ + แถบ Undo
- จัดลำดับ: ลาก ⋮⋮ หรือคลิกเลขลำดับแล้วพิมพ์ตำแหน่ง · ค้นหาในคิว · สลับ 1/2 คอลัมน์
- **ค้นหาคิวสมาชิก**: ดูลำดับของคนหนึ่งในทุกหมวด + คาดว่าจะได้ในอีกกี่รอบ
- สมาชิกทั่วไปเห็นกล่อง "คิวของคุณ #N"
- **History**: Copy ข้อความประกาศแบบมีเลข (เหมือนตอนรัน) · ▾ รายชื่อบรรทัดเดียว / แท็กทุกคน `<@id>` · Undo (เฉพาะรอบล่าสุด) · Delete

## Calendar `/calendar`

- ปฏิทินรายเดือนทุกรอบ GL/WOE, ชิปรอบบอกจำนวนลา (สีตามสัดส่วน), รอบพักเป็นลาย
- แผงรายละเอียด: ผลกระทบต่ออาชีพ, รายชื่อลา + โควต้า, ลาที่ถูก void, ไปกระดานปาร์ตี้
- สรุป: รอบถัดไป, ลาที่นับ/void/ล่วงหน้า, อีเวนต์ที่มีคนลามากสุด · ค้นหาชื่อ · มือถือแสดงเป็นรายการ

## Activity Log `/activity`

- ไทม์ไลน์แยกตามวัน ช่วง 24h / 7 / 30 / 90 วัน / ทั้งหมด (สูงสุด 500 รายการ)
- KPI: เข้าใหม่, ออก/ถูกเตะ (สุทธิ), ลา/ขอลาล่วงหน้า, เปลี่ยนอาชีพ
- กรองหมวด: สมาชิก / การลา / อาชีพ / แอดมิน · ค้นหาชื่อหรือรายละเอียด
- *(แอดมิน)* ลบบรรทัด log (ไม่กระทบการนับลา — ใช้กระดานปาร์ตี้หรือ Void leaves แทน)

## Leave Stats `/attendance`

- เลือกกระดาน, ช่วง 7/30/90 วัน/ทั้งหมด หรือ Custom range
- KPI: ลาในช่วงนี้ (แยกกระดาน), คนที่ลา, **เกินโควต้าเดือนนี้**, ใช้ครบโควต้า
- แต่ละคน: แท่งจำนวนลาในช่วง + **จุดโควต้าเดือนนี้ต่อกระดาน** (เหลือง = ใช้แล้ว, แดง = เกิน) + ลาล่าสุด
- ซ่อนคนที่ไม่ลาเป็นค่าเริ่มต้น, เรียงมากสุด/ชื่อ, ค้นหา
- *(แอดมิน)* **Declare a break (void leaves)** — ประกาศช่วงพัก ใบลาในช่วงนั้นไม่นับสถิติ/โควต้า และรอบนั้นไม่นับเข้า-ขาด

## Check-in [Voice] `/checkin`

- เลือกอีเวนต์ (Tyr Cup / WOE) และรอบจากแถบการ์ด 12 รอบล่าสุด (% มา, LIVE, break) หรือ "Older…"
- KPI: มา (ไม่นับคนลา), ขาดไม่ลา, ลา, เวลาอยู่เฉลี่ย (+ มาสาย/ออกก่อน)
- กรอง: ทั้งหมด / มา / มาสาย / ออกก่อน / ลา / ขาด · ค้นหา · **CSV**
- แต่ละคน: สถานะ, **แถบเวลาในห้อง** (เส้นขีด = เวลาเริ่ม/จบ), นาทีที่อยู่, โน้ต *(แอดมินแก้ได้)*
- กติกา: เข้าห้องแม้ชั่วขณะ = มา · ลาไว้ = ไม่ขาด · "มาสาย/ออกก่อน" = ช้า/ออกก่อนเกิน 5 นาที (แค่ป้ายแสดงผล)

## PVP Stats `/pvp-stats`

- สมาชิกกรอก/อัปเดตสถิติของตัวเอง (ทุกครั้งเป็นประวัติใหม่) · แอดมินเพิ่ม/แก้ให้ใครก็ได้ (+ Add / Edit ในตาราง)
- ตารางเลื่อนในกรอบ หัวตารางติดบน, Last Updated นับทั้งการกรอกใหม่และการแก้ไข, เกิน 14 วัน = เก่า
- มุมมองวิเคราะห์: แถบอาชีพ (จำนวน/ทั้งหมด), จัดกลุ่มตามอาชีพ (คนที่เล่นเป็นอาชีพรองแยกส่วน), badge อันดับในอาชีพ, heatmap เทียบค่ามัธยฐาน, ธง ⚠ ต่ำกว่า 80% ของค่ามัธยฐานใน **Key PVP stat** ของอาชีพ
- **Compare** เปิดหน้าต่างกลางจอ เทียบหลายคน (ค่าฐาน, Δ, แท่ง, เฉพาะที่ต่าง)
- หน้าประวัติรายคน `/pvp-stats/[memberId]`

## Manage Classes `/classes` *(แอดมิน)*

- การ์ดต่ออาชีพ: อีโมจิ, จำนวนคนเล่นหลัก/รอง, เลือกสี และ **Key PVP stat** ได้ทันที, เลื่อนลำดับ, แก้ชื่อ/อีโมจิ, ลบ
- KPI: จำนวนอาชีพ, มีคนเล่นหลัก, ยังไม่ตั้ง key stat, ไม่มีใครเล่น
- การเปลี่ยนชื่ออาชีพจะอัปเดตสมาชิก/อาชีพรอง/ที่นั่งในปาร์ตี้ให้อัตโนมัติ
